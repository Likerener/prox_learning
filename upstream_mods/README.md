# Modifications to upstream repositories

These repositories are not ours to push to (allenai/molmospaces,
allenai/MolmoBot, Physical-Intelligence/openpi, octo-models/octo), so the work
done in them is preserved here instead: a diff of the tracked files we changed,
and a copy of the files we added.

The substantial pieces are the ACT and pi0 policy adapters for molmospaces
(act_molmo_policy.py, act_debug_policy.py, start_pi0_server.py) and the rollout
evaluation entry points used for the ACT and pi0 numbers.
